## 🔍 About Me

I'm passionate about combining physics, computation, and system design to explore fundamental science and build impactful tools. My current research focuses on:

- **Terahertz quantum optics & structured light**
- **Relativistic laser-plasma interactions**
- **HPC-driven simulation & parallel computing**

I’ve contributed to both theoretical modeling and large-scale simulation tools using frameworks like **WarpX**, **Smilei**, and **AMReX**. My code enables high-precision modeling of THz polarization, spin dynamics, and photonic transport in plasma-based environments.
